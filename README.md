# ATM Simulator

A desktop ATM simulator built with C# and WPF, featuring PIN-based login, balance inquiry, deposits and withdrawals, and a state machine-driven UI flow.

## Background

This project is based on the "ATM" exercise commonly used in the **Certified LabVIEW Developer (CLD)** exam preparation materials by National Instruments. The original exercise is typically implemented in LabVIEW; I reimplemented it in C#/WPF as a way to deepen my software development skills outside of LabVIEW.

## Technologies

- C# / .NET
- WPF (Windows Presentation Foundation)
- File-based data persistence

## What it does

- Login via PIN
- Check account balance
- Deposit and withdraw funds, with balance saved to a local file
- Session timeout handling via a state machine

## About this project

This was built independently to strengthen my C# and WPF skills alongside my professional background in LabVIEW development and measurement/test systems.
